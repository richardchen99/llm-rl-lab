# Documentation figures

All screenshots are captures of the running [LLM Reinforcement Learning Lab](https://richardchen99.github.io/llm-rl-lab/) using the public Math verifier example. They show application content only and are also used in the [project research note](https://richardchen99.github.io/blog/llm-rl-lab-note/). Capture date: **2026-09-18**.

Shared configuration: **GRPO; seed 42; group size 8; clip epsilon 0.2; KL coefficient 0.05; learning rate 0.6; six updates of the same sampled group**.

| File | Captured state |
| --- | --- |
| [`overview.jpg`](overview.jpg) | Completed learning stages and evaluation |
| [`policy.jpg`](policy.jpg) | Candidate response probabilities after optimization |
| [`optimizer.jpg`](optimizer.jpg) | Optimizer controls, clipping explorer, and E0–E6 trajectory |

Expected reward is approximately 0.378 initially and 0.466 after six updates; final reference KL is approximately 0.0212. These are exact finite-candidate expectations, rounded for display, not held-out scores.

[`architecture.svg`](architecture.svg) is an original, editable vector schematic prepared for this repository. [`architecture.png`](architecture.png) is its 3,200-pixel-wide raster export. It distinguishes the old sampling policy from the fixed reference and shows the finite-action update loop; see the [README](../../README.md#mathematical-scope).

No screenshot is a synthetic interface image. The framework diagram is drawn with vector shapes and text, not generated by a text-to-image model. Figures contain no editor windows, browser chrome, local paths, or private account details. Numerical values illustrate the stated experiment and are not performance benchmarks.
